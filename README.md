# 我的第一个 GitHub 项目

这个项目是一个钢琴项目，21 个键，对应三组音阶（C2.....B2）(C3....B3)(C4.......B4)

## 克隆版本库

操作示例：

- $git clone git@github.com:pbw-langwang/piano_Project.git
- $ git switch -c dev origin/dev

详细细节：https://blog.csdn.net/langwang_100/article/details/107354013
